# Urgent lease fixes — 2026-10-21

## 根因與修正

- 新租約的費用由 `LeaseService::createLeaseCharges()` 存入 `lease_charges.amount`，單位為分。管理端合約卻讀取舊 `leases.rent_price/security_deposit`，不存在的值經 accessor／格式化變成 0.00。租客端的舊押金讀法還有再次除以 100 的問題。
- 合約三個入口現在共用 `LeaseService::getAgreementVariables()`。租金只取本租約 RENT 類費用；Security Deposit、Utilities Deposit 依既有 DEPOSIT 類別與名稱分開，合併押金不冒充單獨 Security Deposit。歷史欄位僅在沒有 charge 且原始欄位有值時回退。缺失明示 `Not recorded`。
- 非月租保留實際金額並標明 daily／weekly／yearly 等週期，不虛構月租換算。Request 補入費用週期的允許值驗證。
- Unit／Room 的既有 `full_address` 只傳回 Property 地址，未包含 Unit Number。共用合約地址現在從租約實際 polymorphic 關聯解析 Unit；Room 另外標示 room number。整棟 Property 不任選旗下 Unit。
- 實際資料庫模板在首頁及 Schedule 使用 `property_address`，Service Package 使用拼錯的 `leasalable_type`。`TENANCY 11` 是模板中 Schedule 的頁面標題。
- 依使用者確認，合約內 `service_package`、`leasalable_type`、`LEASABLE_TYPE` 代表所屬 Property 的 `type`。使用 Property 詳細頁／列表既有的原始 type 顯示方式；保留原本 `property_type` 的其他用途。Property 缺失或 type 空白時明示 `Not recorded`。既有替換支援大小寫；加入 HTML escaping 及 callback replacement，避免值中的 HTML 或 `$&` 影響內容。
- IC 原本後端 `image` 驗證拒絕 PDF，建立／編輯預覽一律使用圖片。現在允許 JPEG、PNG、GIF、PDF，後端以檔案內容推斷 MIME，維持 2048 KB 上限。IC 檔名副檔名改由實際 MIME 取得，維持私有 local disk、原路由及授權方式。建立／編輯的 PDF 使用開啟連結，查看頁使用 PDF object 與開啟連結 fallback。
